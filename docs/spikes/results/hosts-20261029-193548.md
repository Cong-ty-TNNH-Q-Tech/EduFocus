## 8. Giới hạn quan sát

- Hosts chỉ chặn domain exact; không phân biệt URL/path, nên block page áp dụng cho mọi path của domain.
- Block page chỉ phục vụ HTTP; truy cập HTTPS thường báo lỗi kết nối/SSL thay vì hiển thị trang chặn.
- Hosts không tạo log truy cập HTTPS; server chỉ ghi nhận request HTTP thực tế đến cổng block page.
- DoH/DoT, VPN, proxy hoặc browser extension có thể bypass hosts.
- Học sinh có quyền admin có thể sửa hosts hoặc dừng tiến trình; self-heal/journal chỉ giảm thiểu, không chống admin.
